# Low-Touch Micro-SaaS — Operating Pack

A complete structure and task-list framework for building and running a
one-person, subscription software business from Australia, designed around a
hard constraint: **~10 hours per week once it is running.**

Everything here is written to be executed, not admired. Files are numbered in
the order you need them.

## Parameters this pack was written against

| Parameter | Value |
| --- | --- |
| Model | Micro-SaaS — recurring subscription, self-serve, B2B |
| Jurisdiction | Australia (ABN / ASIC / ATO / ACL) |
| Setup budget | $1,000 – $5,000 AUD |
| Steady-state time | ~10 hrs/week |
| Headcount | You, plus contractors bought by the task |

## Placeholders

These appear throughout. Fill them once you have picked an idea:

- `<PRODUCT>` — product name
- `<DOMAIN>` — primary domain
- `<ENTITY>` — trading entity (sole trader name or Pty Ltd)
- `<ICP>` — ideal customer profile, one sentence

## How to use it

1. Read `01`, then score at least three ideas with `03` — including any of
   your own. Do not skip to building.
2. Run `04`. If it fails, go back to `02`. A failed validation costs three
   weeks; a failed build costs six months.
3. Work `15-task-list-master.md` top to bottom. It is the single source of
   truth for what is done.
4. Once live, the only file you open regularly is `10-operating-rhythm.md`.

## A note on the numbers in here

Dollar figures for Australian government fees, thresholds and software pricing
are indicative and were correct to the best of the author's knowledge at time
of writing. ASIC fees are indexed on 1 July each year. **Verify every figure
against the primary source before you rely on it.** Nothing in this pack is
legal, tax or financial advice.
